# Computer Repair Shop Management System

## Current Features

- Add customers
- Create repair tickets
- View customers and repair tickets
- Update repair-ticket status
- Graphical interface built with Tkinter
- Three classes: Customer, RepairTicket, and RepairShop
- Uses a list, dictionary, and tuple

## Files

- `main.py` contains the graphical user interface.
- `models.py` contains the three main classes.

## How to Run

1. Download both Python files into the same folder.
2. Open the folder in Visual Studio Code.
3. Open the terminal.
4. Run:

   python main.py
