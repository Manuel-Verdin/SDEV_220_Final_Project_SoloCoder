# Computer Repair Shop Management System

## Features
- Add, update, search, and delete customers
- Create, update, search, and delete completed repair tickets
- Track Waiting, In Progress, and Completed statuses
- Store repair costs
- Show a complete report
- Save and load data automatically with JSON
- Input validation and error messages

## Requirements Met
- Tkinter graphical interface
- Three main classes: Customer, RepairTicket, RepairShop
- Dictionary, list, and tuple collections
- File saving/loading
- Unit tests
- No outside packages required

## Run
```bash
python main.py
```
Or on Windows:
```bash
py main.py
```

## Test
```bash
python -m unittest test_models.py
```
